Compreendendo a

Conceito

O que a nota fiscal registra?

A nota fiscal é o documento que registra uma operação de compra. Ela reúne informações sobre:

🤝 Quem realizou a venda

👤 Quem aparece como comprador

📅 Quando foi registrada

📦 Quais produtos foram adquiridos

Mais do que visualizar um documento, precisamos compreender o que suas informações representam para localizar os dados durante o atendimento.

Foco

Precisamos interpretar tudo?

A nota fiscal possui diversos números e códigos. Em nossa rotina, não precisamos interpretar todos.

Nossa leitura deve ser direcionada para:

  • Identificar a data;
  • Localizar o produto relacionado ao atendimento;
  • Confirmar se o produto é Hisense ou Gorenje;
  • Verificar se existem informações suficientes para seguir.
Direcionamento

As perguntas que orientam nossa leitura

  • Quando a compra foi registrada?
  • A data de emissão está identificável?
  • Qual produto foi adquirido?
  • A descrição permite reconhecer o item?
  • O produto é Hisense ou Gorenje?
  • As informações permitem confirmar a marca?
  • As informações são suficientes?

Quando sabemos o que precisamos confirmar, a leitura se torna mais simples.

Passo 1

Como confirmar a data de emissão?

Uma nota fiscal pode apresentar diferentes datas e horários. Para localizar a correta:

  • Procure o campo “Data de emissão” ou equivalente;
  • Confirme o nome do campo antes de utilizar;
  • Verifique se a informação está completa e legível;
  • Não confunda a emissão com outras datas (saída, protocolo).

Não utilize uma data apenas por ser a primeira encontrada.

Passo 2

Qual produto está relacionado?

  1. Encontre a área de produtos ou serviços;
  2. Considere o produto informado pelo consumidor;
  3. Leia a descrição dos itens necessários;
  4. Diferencie o produto de acessórios ou serviços;
  5. Confirme qual linha corresponde ao atendimento.

⚠️ O primeiro item da nota nem sempre será o produto que precisa de atendimento.

O Ponto de Partida

Comece pela descrição do item

Ela pode reunir informações como:

Marca

Categoria do produto

Modelo ou referência

Tamanho ou capacidade

Tecnologia

Cor ou versão

A descrição é o principal ponto de partida para reconhecermos o produto.

Pistas Visuais

Quais pistas ajudam a reconhecer?

  • Marca: Hisense ou Gorenje.
  • Categoria: TV, refrigerador, ar-condicionado.
  • Modelo/Ref: Diferencia versões da mesma categoria.
  • Características: Tamanho, capacidade, cor.

Exemplo Prático

Como interpretar a descrição?

Observe o exemplo retirado da nota:

TV 55 POL HISENSE MOD 55A6NV 4K
  • TV: Categoria
  • 55 POL: Tamanho
  • HISENSE: Marca
  • 55A6NV: Modelo/Referência
  • 4K: Característica

"Mesmo quando as informações aparecem juntas, podemos separá-las pela função que representam."

Atenção

E quando a descrição está abreviada?

Observe este exemplo: TV 4K DLED 58P SMART

✅ Permite reconhecer:

Categoria (TV), tamanho (58p), características (4K, DLED, Smart).

❌ Não confirma sozinha:

A marca (Hisense/Gorenje) e o modelo completo.

Quando a descrição não apresenta todas as respostas, precisamos consultar outras informações e utilizar a sondagem.

Ação Prática

Descrição abreviada exige cautela

Se a descrição não traz a marca ou o modelo completo, não assuma que é Hisense ou Gorenje apenas por ser uma TV.

É necessário realizar a sondagem com o consumidor para confirmar os detalhes.

Nem todo código
é o modelo.

Códigos

Vários códigos no mesmo item

Na área de produtos, podemos encontrar diferentes números e referências. Eles podem representar:

  • O código utilizado pela revenda;
  • O modelo ou a referência do produto;
  • O GTIN/EAN;
  • O NCM;
  • O número de série.

Estar próximo à descrição não significa que o código representa o modelo.

Entendendo os Códigos

O que cada identificação representa?

Código da Revenda

Referência utilizada pela loja. Pode não corresponder ao modelo do fabricante.

Modelo ou Referência

Identifica uma versão do produto. Pode aparecer completo ou abreviado.

GTIN/EAN

Código comercial associado ao item (código de barras). Não deve ser interpretado como o modelo.

Entendendo os Códigos

O que cada identificação representa?

NCM

Classificação fiscal da mercadoria. Não identifica o modelo exato do produto.

Número de Série

Identifica uma unidade específica. É diferente do modelo e pode não aparecer na nota.

Cada identificação possui uma finalidade diferente.

Passo a Passo

Por onde devemos começar?

Antes de utilizar um código:

  1. Leia a descrição completa do item;
  2. Identifique a marca, categoria e características;
  3. Procure uma indicação de modelo ou referência;
  4. Observe o nome do campo associado ao código;
  5. Confirme o que a informação representa.

Se o código não estiver claramente identificado, não o utilize sozinho para concluir qual é o produto.

Exemplo 1

Código da revenda diferente do modelo

Código: 20804
Descrição: TV 55 POL HISENSE MOD 55A6NV 4K
  • 20804: Código utilizado pela revenda;
  • 55A6NV: Modelo ou referência;
  • 4K: Característica do produto.
